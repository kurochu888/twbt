## 資料涵蓋範圍

| 標的 | 真實資料 | 模擬（上市前） | 模擬方式 |
|---|---|---|---|
| 大盤加權指數 | 1990-01-04 起 | — | — |
| 大盤報酬指數（含息） | 2003-01-02 起 | 1990～2002 | 價格指數 + 估計股息（由 2003 年後兩指數差距推得） |
| 0050 | 2010-01-04 起 | 1990～2009 | 大盤含息報酬 + 校正年化差距 |

| 00675L | 2017-05-02 起 | 1990～2017 | 同上 |

模擬參數都用「真實資料重疊期間」校正，校正結果見 `adjusted/long/calibration.txt`。

## 輸出檔案（在 `twbt_data/adjusted/`）

**真實資料**：`0050.csv`、`00631L.csv`、`00675L.csv`

| 欄位 | 說明 |
|---|---|
| `open` `high` `low` `close` | 原始價格（實際成交價，撮合與計算手續費用這個） |
| `adj_open` … `adj_close` | 還原價（還原除權息與分割，最新一天 = 原始價） |
| `adj_factor` | 原始價 × 這個 = 還原價 |
| `ret` | 每日總報酬（配息再投入） |
| `event` | 當天的除息或分割事件 |

**含模擬的長期序列**：`long/0050_long.csv` 等

| 欄位 | 說明 |
|---|---|
| `ret` | 每日總報酬 |
| `adj_close` | 還原價（與真實段在上市日接上） |
| `is_synthetic` | 1 = 模擬、0 = 真實 |

**大盤**：`TAIEX.csv`（加權指數 `close`、報酬指數 `tr_close`）、`long/TAIEX_long.csv`（含 1990 年起的含息報酬 `tr_ret`、`tr_index`）

## 買進持有回測（筆記本第 5～8 格）

| 格子 | 功能 |
|---|---|
| 5 共同設定 | 投入金額、手續費折扣、是否用模擬資料、模擬段是否套用台灣50超額報酬 |
| 6 自訂區間 | 指定起訖日，列出各項指標並畫資產成長與回撤圖 |
| 7 固定長度滾動 | 例如所有 10 年區間（每月一個起點），看報酬與回撤的分布、最差與最好的區間 |
| 8 隨機區間 | 隨機抽 N 個區間，長度可設範圍（例如 5～15 年）；SEED 固定可重現 |

規則：起始日後第一個交易日以收盤價買進，結束日前最後一個交易日以收盤價賣出；配息再投入；
扣買賣手續費（0.1425% × 折扣，最低 20 元）與 ETF 證交稅 0.1%；大盤是比較基準，不扣成本。
分割暫停交易期間報酬視為 0。

在 Python 裡使用：
```python
from twbt.backtest import BuyHold, describe
bh = BuyHold("twbt_data/adjusted")
stats, curves = bh.period("2000-01-01", "2010-12-31")
roll = bh.rolling(10)                  # 所有 10 年區間
rnd = bh.random(500, (5, 15), seed=42) # 隨機 500 個 5～15 年區間
describe(roll)                         # 分布摘要
```

## 驗證

- 0050 在 2018-01-02 ~ 2026-06-09：還原價報酬 +558.7%、原始價 +25.3%；FinLab 公布的是 +558.5%、+25.3%。
- 每一次除息都有證交所官方的除權息紀錄對應，程式會自動檢查「沒有事件卻大幅跳動」的日子。

## 要注意的地方

- **新的分割**不會自動抓到：分割要手動加進 `twbt/data/splits.csv`。如果有新分割還沒加，更新時會出現「無法解釋的跳動」警告。
- **模擬段只是近似**：0050 與大盤的日報酬相關係數約 0.96、正2 約 0.98。適合看大方向（例如 2000 年正2 會跌多深），不適合看精確數字。2003 年前的股息是用近年平均估計的。
- **模擬段的 0050 預設每年贏大盤 1.38%**（2010～2026 年的實測值，主要來自台積電）。在模擬段，大盤幾乎不可能贏 0050；想看保守情境，把第 5 格的 `TW50_EXCESS` 關掉。
- 證交所會封鎖太頻繁的請求，程式預設每次間隔 8 秒以上，不要調低。
