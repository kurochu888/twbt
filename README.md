# twbt：台股回測工具組

自己打造的台股回測工具，一步一步擴充。

## 目前進度

- [x] 第 1 步：資料層（證交所資料下載、本地資料庫、品質檢查）
- [x] **第 2 步：核心標的資料**：大盤、0050、00631L、00675L，含除權息與分割還原、上市前模擬
- [x] **第 3 步：買進持有回測**：自訂區間、固定長度滾動、隨機區間，含手續費與證交稅
- [x] **第 4 步：均線趨勢策略（接刀）**：照 finance-app 的訊號，策略與買進持有並排比較
- [x] **蒙地卡羅測試**：區塊自助抽樣重組歷史報酬，檢驗策略贏買進持有有多穩（網頁「蒙地卡羅」分頁、`scripts/montecarlo.py`）
- [x] **第 5 步：再平衡策略**：固定配置（0050／正2／現金）定期或依偏離門檻調回，可搭配均線訊號
- [ ] 下一步：定期定額、股債配置（需要上櫃債券 ETF 資料）

## 還原價檔案（`data/adjusted/`）

**`data/adjusted/` 的真實資料**：`0050.csv`、`00631L.csv`、`00675L.csv`

| 欄位 | 說明 |
|---|---|
| `open` `high` `low` `close` | 原始價格（實際成交價，撮合與計算手續費用這個） |
| `adj_open` … `adj_close` | 還原價（還原除權息與分割，最新一天 = 原始價） |
| `adj_factor` | 原始價 × 這個 = 還原價 |
| `ret` | 每日總報酬（配息再投入） |
| `event` | 當天的除息或分割事件 |

**含模擬的長期序列**：`long/0050_long.csv` 等

| 欄位 | 說明 |
|---|---|
| `ret` | 每日總報酬 |
| `adj_close` | 還原價（與真實段在上市日接上） |
| `is_synthetic` | 1 = 模擬、0 = 真實 |

**大盤**：`TAIEX.csv`（加權指數 `close`、報酬指數 `tr_close`）、`long/TAIEX_long.csv`（含 1990 年起的含息報酬 `tr_ret`、`tr_index`）

## 買進持有回測

網頁和 Colab 筆記本第 5～8 格功能相同（兩邊的計算已對照驗證，相對誤差 < 1e-8）。

| 格子 | 功能 |
|---|---|
| 5 共同設定 | 投入金額、手續費折扣、是否用模擬資料、模擬段是否套用台灣50超額報酬 |
| 6 自訂區間 | 指定起訖日，列出各項指標並畫資產成長與回撤圖 |
| 7 固定長度滾動 | 例如所有 10 年區間（每月一個起點），看報酬與回撤的分布、最差與最好的區間 |
| 8 隨機區間 | 隨機抽 N 個區間，長度可設範圍（例如 5～15 年）；SEED 固定可重現 |

規則：起始日後第一個交易日以收盤價買進，結束日前最後一個交易日以收盤價賣出；配息再投入；
扣買賣手續費（0.1425% × 折扣，最低 20 元）與 ETF 證交稅 0.1%；大盤是比較基準，不扣成本。
分割暫停交易期間報酬視為 0。

在 Python 裡使用：
```python
from twbt.backtest import BuyHold, describe
bh = BuyHold("data/adjusted")
stats, curves = bh.period("2000-01-01", "2010-12-31")
roll = bh.rolling(10)                  # 所有 10 年區間
rnd = bh.random(500, (5, 15), seed=42) # 隨機 500 個 5～15 年區間
describe(roll)                         # 分布摘要
```

## 均線趨勢策略（接刀）

規則照 [kurochu888/finance-app](https://github.com/kurochu888/finance-app) 的 `computeTrend()` / `runBacktest()`（`twbt/backtest/trend.py`、`docs/engine.js`）：

- **續抱**：全部投入；收盤 < 快線 × 出場乘數 → 全部賣出（出場），轉成接刀中
- **接刀中**：收盤 < min(基準價, 慢線) × (1 − 接刀間距) → 加碼一層（出場現金 ÷ 層數）；基準價 = 上次動作那天的收盤
- **轉回續抱**：(收盤 > 快線 且 前一天收盤 > 前一天快線 且 快線 ≥ 前一天快線 × 轉回斜率) 或 收盤 > 快線 × 強反彈 → 剩下現金全部買進
- 預設參數同 app：正2 快線 120／慢線 240／出場 0.90／間距 0.15／2 層；0050 快線 100／慢線 200／出場 0.95／1 層；轉回斜率 1.002、強反彈 1.03

跟 app 一致的地方：當天收盤成交、均線看「只還原分割、不還原配息」的價格（可切成還原權息）、分割暫停交易的日子不算進均線。
和 app 原始程式（`runBacktest()`）用同一份價格對照：0050、00631L、00675L 每一筆進出日期都相同，每日淨值差 < 0.002%
（差異來自 app 整張 1000 股下單、手續費取整；這裡股數可以有小數）。
2020、2022、2024 三段 00631L 的報酬與回撤跟 finance-app CLAUDE.md 記錄的數字相差 0.5 個百分點以內，0050 2020 上半年 +10.0% / −16.9% 完全相同。

回測區間從中間開始時，策略照當時的狀態建立部位（續抱 = 全買、接刀已接 k 層 = 買 k ÷ 層數、觀望 = 現金）。
均線要先累積「慢線天數」個交易日，在那之前的起點一律延後到均線算得出來的那天（策略與買進持有同一天），
滾動／隨機區間則不列入，避免策略因為還沒訊號而躲過開頭的大跌（例如 1990 年）。

```python
from twbt.backtest.trend import TrendBacktest, TrendParams
tb = TrendBacktest(bh)                                   # bh = BuyHold(...)
r = tb.run("00631L", "2020-01-01", "2022-12-31")         # r.equity、r.bh_equity、r.events
w = tb.rolling(10)                                       # 每列：策略與買進持有的年化、回撤
tb2 = TrendBacktest(bh, {"00631L": TrendParams(ma_fast=150)})   # 改參數
```

## 再平衡策略

`twbt/backtest/rebalance.py`、`docs/engine.js`（兩邊對照 82 個數字一致）：

- **配置**：0050、00631L、00675L、現金的比例（自動換算成加總 100%），曝險 = Σ 比例 × 槓桿倍數
- **規則**：定期（每月／季／半年／年的第一個交易日）、偏離門檻（任一部位偏離目標超過幾個百分點）、或兩者合併（定期檢查、偏離超過門檻才調）；不定期也不設門檻 = 買進後放著（對照組）
- **現金**：每個交易日依年利率計息（預設 1%）
- **搭配均線**：正2 部位目標 = 配置比例 × 均線狀態（續抱 1、接刀 k ÷ 層數、出場 0），訊號那天只調那一檔
- 結果並排比較：同配置不再平衡、0050 買進持有、00631L 買進持有、00631L 均線策略（同一天開始）

```python
from twbt.backtest.rebalance import RebalBacktest, RebalConfig
rb = RebalBacktest(bh)                                      # bh = BuyHold(...)
cfg = RebalConfig({"00631L": .5, "CASH": .5}, freq="Q", band=.05, cash_rate=.01, trend=True)
out = rb.run(cfg, "2000-01-01", "2026-10-22")               # out["策略"]、out["同配置不再平衡"]
w = rb.rolling(cfg, 10)
```

## 蒙地卡羅測試

stationary block bootstrap：從歷史日報酬隨機挑起點、連續取一段（平均長度 = 區塊長度、幾何分布），接成一條條 N 年的行情；
總報酬與訊號用的價格報酬同一天一起抽。每條先讓均線累積，之後策略與買進持有同一天開始、都扣成本。
區塊 1 天 = 完全打亂、沒有趨勢（對照組）；真實台股 1～6 個月的變異數比 1.14～1.35，有趨勢延續，3～6 個月的區塊最接近現實。

網頁「蒙地卡羅」分頁（策略選均線趨勢時出現）與 `python scripts/montecarlo.py` 同一套方法（亂數不同，統計結果相差在抽樣誤差內）。

## 驗證

- 0050 在 2018-01-02 ~ 2026-06-09：還原價報酬 +558.7%、原始價 +25.3%；FinLab 公布的是 +558.5%、+25.3%。
- 每一次除息都有證交所官方的除權息紀錄對應，程式會自動檢查「沒有事件卻大幅跳動」的日子。

## 要注意的地方

- **新的分割**不會自動抓到：分割要手動加進 `twbt/data/splits.csv`。如果有新分割還沒加，更新時會出現「無法解釋的跳動」警告。
- **模擬段只是近似**：0050 與大盤的日報酬相關係數約 0.96、正2 約 0.98。適合看大方向（例如 2000 年正2 會跌多深），不適合看精確數字。2003 年前的股息是用近年平均估計的。
- **模擬段的 0050 預設每年贏大盤 1.38%**（2010～2026 年的實測值，主要來自台積電）。在模擬段，大盤幾乎不可能贏 0050；想看保守情境，把第 5 格的 `TW50_EXCESS` 關掉。
- 證交所會封鎖太頻繁的請求，程式預設每次間隔 8 秒以上，不要調低。
